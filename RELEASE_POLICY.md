# Release policy

Each TEF release ID identifies a research work. Manuscript versions identify revisions of that work.

- Major versions record substantive scientific changes such as new assumptions, derivations, quantitative results, or interpretations.
- Minor versions record corrections, references, clarifications, figures, or formatting changes that do not materially alter the scientific result.
- Zenodo remains the authoritative archive for the frozen manuscript and version-specific DOI.
- Git tags and GitHub Releases, when created, use namespaced identifiers such as `TEF-2026-001-v5.1` to avoid collisions between papers.
- Older releases remain visible. A released artifact is never overwritten to conceal or replace its history.
- External publication requires an explicit author decision. Repository automation may prepare and verify a release but does not decide to publish it.
