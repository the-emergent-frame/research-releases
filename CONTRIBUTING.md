# Contributing

This repository preserves formally released research artifacts. Changes to a frozen manuscript are made only through a new manuscript version and archival record; released files are not silently replaced.

Use GitHub Issues to report:

- a calculation that does not reproduce;
- a mismatch between source, PDF, hash, or citation metadata;
- a broken build instruction or link;
- a narrowly scoped technical error in the release materials.

When reporting a scientific objection, identify the manuscript, version, DOI, equation or section, and the specific claim at issue. Publication on Zenodo or GitHub does not imply peer review or acceptance of the underlying physical hypotheses.

Do not submit third-party papers, copyrighted reference files, private correspondence, or unpublished TEF working notes.
